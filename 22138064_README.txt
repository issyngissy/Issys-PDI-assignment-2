SMART GREENHOUSE MONITORING SYSTEM

About the program

This is a Java menu program for greenhouse sensor readings. It reads the data
from data.csv, lets the user check statistics, add a new reading, delete a
reading, and then saves the data back to the CSV file.

The program also writes the menu output to a file called logged_data.


Compile

Run this from the project folder:

    javac -d bin Java/*.java

This puts the compiled class files in the bin folder.


Run

After compiling, run:

    java -cp bin Main

The menu should then appear in the terminal.


Menu options

1. Overall statistics
2. Statistics by zone
3. Statistics by sensor type
4. Add a reading
5. Delete a reading
6. Exit

The statistics submenu can show the total, average, minimum, maximum, number
outside the safe range, and percentage outside the safe range.


CSV file

The file must be called:

    data.csv

It needs to be in the folder that the program is run from.

The header is:

    day,month,year,hour,minute,sensorID,sensorType,zone,value

Example:

    15,5,2026,14,30,TMP100,temperature,ZoneA,22.5

The first line is treated as the header and is skipped when the file is loaded.


Sensor types

The program uses these sensor types:

- temperature
- humidity
- soilMoisture
- light

The menu uses these zones:

- ZoneA
- ZoneB
- ZoneC

Safe ranges are checked in SensorReading.java:

- temperature: 18.0 to 30.0
- humidity: 40.0 to 70.0
- soilMoisture: 30.0 to 60.0
- light: 300.0 to 1200.0


Files

Java/Main.java
Starts the program, opens the logger, loads the CSV file, starts the menu, and
closes the logger at the end.

Java/Menu.java
Contains the main menu and most of the user input code.

Java/GreenhouseDataStorage.java
Loads data.csv and saves the readings back to data.csv.

Java/SensorArray.java
Stores the readings in an array. It also adds, deletes, filters, counts, and
checks for duplicate sensor IDs.

Java/SensorReading.java
Stores one sensor reading and checks if it is outside the safe range.

Java/Timestamp.java
Stores the day, month, year, hour, and minute for a reading.

Java/Math.java
Does the statistics calculations.

Java/Validator.java
Checks input values before they are used.

Java/Logger.java
Prints messages to the screen and writes the same messages to logged_data.


Logging

The log file is:

    logged_data

The program appends to this file each time it runs. If the file is deleted, the
program will make it again the next time it runs.


Notes

The program checks for empty values, invalid numbers, invalid dates, invalid
times, invalid sensor types, and duplicate sensor IDs.

The date check is basic. It checks that the day is between 1 and 31 and the
month is between 1 and 12, but it does not check every real calendar date.
