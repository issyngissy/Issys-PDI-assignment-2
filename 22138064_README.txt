================================================================
  SMART GREENHOUSE MONITORING SYSTEM
================================================================


WHAT IT DOES
============

A console program for managing a CSV log of greenhouse sensor
readings. On startup it loads the CSV into memory, then offers
a menu to:

  * view stats for the whole greenhouse, a single zone, or a
    single sensor type (total, average, min, max, count of
    readings outside the safe range, and that count as a
    percentage)
  * add a new reading (with validation, written back to the CSV)
  * delete an existing reading (also written back to the CSV)
  * exit

Each reading is one CSV row holding a timestamp, sensor ID,
sensor type, zone, and value. The four supported sensor types
are temperature, humidity, soilMoisture, and light. Each type has
a hard-coded safe range and any reading outside its range is
flagged.


DEPENDENCIES
============

  * Java JDK 11 or newer (tested on JDK 17)
  * Java Standard library  

The only `java.io` classes used are BufferedReader, BufferedWriter,
FileReader, FileWriter, InputStreamReader, and IOException.


COMPILE (Linux terminal)
========================

From the project root:

    javac -d bin Java/*.java

This compiles every `.java` file under `Java/` and writes the
resulting `.class` files into `bin/`. The `bin/` directory is
created if it does not already exist.


RUN
===

From the project root, after compiling:

    java -cp bin Main

The menu opens in the terminal. Pick options by typing the
matching number and pressing Enter.


FILE STRUCTURE
==============

The CSV file must sit in the working directory you launch the
program from. It must be named exactly:

    data.csv

The expected layout when running from the project root looks
like this:

    PDI Portfolio/
        Java/                          (source files)
            Main.java
            Menu.java
            Logger.java
            SensorArray.java
            SensorReading.java
            GreenhouseDataStorage.java
        bin/                           (compiled .class files)
        data.csv                       (required, in the cwd)
        logged_data                    (created on first run)

CSV format. The header row is required and is skipped on load:

    day,month,year,hour,minute,sensorID,sensorType,zone,value
    15,5,2026,14,30,TMP100,temperature,ZoneA,22.5
    ...

If `data.csv` is missing, the program prints a warning and
starts with an empty in-memory array. Adding a reading from the
menu will create the file.


LOG FILE
========

Every line printed to the terminal is also written to a plain
text log file named:

    logged_data

The log file lives in the same working directory as `data.csv`.
Each run appends to it. Sessions are bracketed by the lines
`starting session...` and `ending session`, so individual runs
can be picked out by eye. Delete the file to clear it. It will
be recreated on the next run.
