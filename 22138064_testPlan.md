# Test Plan for the Smart Greenhouse Monitoring System

All tests are run manually from the terminal. Compile first with `javac -d bin Java/*.java`, then run with `java -cp bin Main`. The CSV file is `data.csv` in the working directory unless a row says otherwise.

| Test ID | Test Description | Input | Expected Output | Actual Output | Pass/Fail |
|---|---|---|---|---|---|
| **CSV LOADING** | | | | | |
| T01 | Load a valid CSV file | `data.csv` exists with header plus 10 well-formed rows | The `SensorArray` is populated with all 10 readings. No warnings printed. | | |
| T02 | Load a missing CSV file | `data.csv` is absent from the working directory | Error message `Error loading file 'data.csv': ...` printed. Empty `SensorArray` returned. Program continues to the menu. | | |
| T03 | Load a CSV with malformed rows | `data.csv` contains (a) a row missing two fields, (b) a row with `day = abc`, (c) a row with `sensorType = wind` | A `Warning: skipped invalid row N: ...` line is printed for each bad row. Remaining valid rows still load. | | |
| **MENU INPUT VALIDATION** | | | | | |
| T04 | Non-numeric input at main menu | At ` choice >> `, type `abc` and press Enter | Error `!! integer must be between 1 and 6.` is printed. Prompt repeats. | | |
| T05 | Out-of-range integer at main menu | At ` choice >> `, type `9` | Error message. Prompt repeats. | | |
| T06 | Empty input at main menu | At ` choice >> `, press Enter with nothing typed | Error message. Prompt repeats. | | |
| T07 | Negative integer at main menu | At ` choice >> `, type `-1` | Error message. Prompt repeats. | | |
| **STATISTICS CALCULATIONS** | | | | | |
| T08 | Total readings (entire greenhouse) | Main menu `[1]`, then sub-menu `[1]` | `total ............ N`, where N is the number of rows loaded from CSV. | | |
| T09 | Average value | Main menu `[1]`, then sub-menu `[2]` | `average .......... X`, where X is the sum of every `value` divided by the count. | | |
| T10 | Minimum value | Main menu `[1]`, then sub-menu `[3]` | `minimum .......... X`, where X is the smallest `value` across all readings. | | |
| T11 | Maximum value | Main menu `[1]`, then sub-menu `[4]` | `maximum .......... X`, where X is the largest `value` across all readings. | | |
| T12 | Out-of-range count | Main menu `[1]`, then sub-menu `[5]` | Count of readings whose `value` is outside the safe range for that sensor type (temperature 18 to 30, humidity 40 to 70, soilMoisture 30 to 60, light 300 to 1200). | | |
| T13 | Out-of-range percentage | Main menu `[1]`, then sub-menu `[6]` | `(outOfRangeCount / totalReadings) * 100`, printed as a `double`. | | |
| **FILTERING** | | | | | |
| T14 | Filter by zone | Main menu `[2]`, pick a zone from the printed list | The stats sub-menu only operates on readings whose `zone` matches. `total` equals the number of readings in that zone. | | |
| T15 | Filter by sensor type | Main menu `[3]`, pick a type from the printed list | The stats sub-menu only operates on readings whose `sensorType` matches. | | |
| **ADD READING** | | | | | |
| T16 | Add a valid reading | Main menu `[4]`. Enter `TMP100`, `temperature`, `ZoneA`, `22.5`, `15`, `5`, `2026`, `14`, `30` | New reading is appended. `total` increases by 1. `data.csv` is rewritten with the new row at the bottom. | | |
| T17 | Add reading with invalid sensor type | At ` type ... >> `, type `wind` | Error `!! unknown sensor type.` is printed. Prompt repeats until a valid type is entered. | | |
| T18 | Add reading with invalid date field | At ` day (1-31) >> `, type `32` | Error message about valid range. Prompt repeats. | | |
| **DELETE READING** | | | | | |
| T19 | Delete a valid reading | Main menu `[5]`, pick an existing index from the printed list | The reading at that index is removed. `total` decreases by 1. `data.csv` is rewritten without that row. | | |
| T20 | Delete from an empty array | After loading an empty CSV (or deleting all readings), pick main menu `[5]` | `!! no readings to delete.` is printed. User is returned to the main menu without error. | | |
| **LOG FILE** | | | | | |
| T21 | Log file session markers | Run the program, navigate any menu, exit via `[6]` | The `logged_data` file contains `starting session...` near the top and `ending session` near the bottom for this run. | | |
| T22 | Log file mirrors console output | Run the program, navigate through several menu options | Every line printed to the terminal during the session also appears, in the same order, in `logged_data`. | | |
